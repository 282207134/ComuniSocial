# 应用界面截图索引

以下为 Android 15 / API 35 模拟器中的 Flutter 应用运行截图。共 39 张，包含独立页面及其关键状态。Pixso 原始参考另外存放于 `design/`，未混入此目录。

截图来自自动化测试的同一分辨率设备；滑动删除状态中的触点标记是测试手势提示。
